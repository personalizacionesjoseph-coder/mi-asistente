LIMITACIÓN DE VERIFICACIÓN
Este entorno no contiene el Android SDK, por lo que no se pudo ejecutar aquí el build Android real ni instalar la APK en un dispositivo. El repositorio incluye GitHub Actions para realizar esa compilación con Android SDK 36. El resultado esperado del workflow es el artefacto “Lyra-V5.1-APK”.

WAKE WORD
